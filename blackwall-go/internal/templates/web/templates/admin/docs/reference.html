Glossary
Approval request
A queued mutation submitted by an actor without the matching _direct capability, awaiting a reviewer's decision.
Capability
Named permission like view_users or manage_clients; granted by role.
CryptBin
End-to-end encrypted blob storage. Server holds ciphertext + a wrapped DEK; only the user with the right key (and optional WebAuthn binding) can decrypt.
DEK
Data Encryption Key. Per-CryptBin-item AES-256 key generated client-side; wrapped under the server-side KEK before storage.
KEK
Key Encryption Key. Server-side XChaCha20-Poly1305 key used to wrap each CryptBin DEK. Single key, identified by version tag.
Privilege level
Numeric rung within a project's privilege ladder; lower number = more privilege.
Scope (admin)
Set of organisations + projects the current admin can see / act on.
Scope (OAuth)
Space-separated list of permissions a client requests from BlackWall (e.g. openid profile email).
Sign counter
WebAuthn authenticator-incremented value that detects credential cloning.
