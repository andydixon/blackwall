BlackWall is an OAuth 2.1 + OpenID Connect authentication service with WebAuthn (passkey) authentication. It is designed for organisations that need a single, auditable, passwordless identity surface for both staff and external integrations.

What you can do here
  • Define organisations, each with their own admin user and project portfolio.
  • Run projects with bespoke privilege ladders and per-user assignments.
  • Issue and revoke OAuth clients for downstream applications.
  • Enrol users with one-time WebAuthn credentials; passwords are never used.
  • Track everything through an integrity-chained audit log with CSV export.
  • Hold sensitive payloads in CryptBin with end-to-end client-side encryption.
Capability model in one sentence

The current viewer's role determines a fixed set of named capabilities; some capabilities apply mutations directly while others enqueue approval requests for review.
