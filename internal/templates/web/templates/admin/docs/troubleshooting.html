Triage order
  1. Check /admin/audit filtered by the user's UUID, the failing event_type, and a 5-minute window. The metadata_json column usually has the precise reason.
  2. Cross-reference the user's correlation ID. If they were given an error trace code, decode it at /admin/error-trace.
  3. Check the dashboard for a recent spike in fail events of the relevant type — the issue may not be specific to one user.
Common faults
SymptomLikely causeAction
OAuth flow ends with access_deniedUser has no project assignment, or project status is inactive.Open the user detail page and add an assignment.
OAuth flow ends with invalid_request: nonce requiredOIDC client didn't send nonce.Configure the client to include nonce; required for openid scope.
OAuth flow ends with invalid_request: Nonce replay detectedClient reused a nonce from a previous flow.Client must generate a fresh per-session nonce. See OIDC §3.1.2.1.
OAuth flow ends with invalid_request: max_age must be a non-negative integerThe relying party sent a negative, fractional, or non-numeric max_age.Send whole seconds such as max_age=3600, or omit the parameter.
User is prompted for a passkey again during OAuthThe relying party requested max_age and the existing authentication is older than that limit.This is expected. Check the oidc.reauthentication.required audit event and its max_age_seconds metadata.
OAuth flow ends with unauthorized_client for an openid requestOIDC is disabled on that OAuth client.Open the client in Admin and enable OIDC, or remove openid from the relying party's request.
WebAuthn assertion fails on a known-good credentialSign-counter regression — possible cloned authenticator.Delete that credential and ask the user to re-enrol on the original device.
WebAuthn assertion fails with "user verification flag not set"Authenticator doesn't perform UV (e.g. legacy U2F key).Use a UV-capable authenticator (built-in biometrics or a security key with PIN).
Form submissions silently failCSRF token mismatch — usually caused by the user opening the form in one tab and submitting after another tab logged them out.Ask the user to refresh the form and resubmit.
CryptBin item refuses to decryptKEK was rotated without rewrap, or the bound credential was deleted.Check kek_version in the item meta; if it doesn't match the configured KEK, the item is unrecoverable.
Unauthenticated 429 on /oauth/tokenPer-IP rate limit hit (default 60/min).Investigate security.ratelimit.hit entries for that IP — could be runaway client retry or an attack.
Audit chain hash mismatch reportedDatabase row was edited or rolled back outside of normal application flow.Treat as an integrity incident; restore from backup and audit who had write access.
Diagnostic surfaces
  • /admin/scope — what your role can see and act on right now.
  • /admin/error-trace — decode the short opaque code shown to end-users on error pages.
  • /admin/maintenance — last run results for each cleanup job.
  • /metrics + your scrape stack — quantitative views.
